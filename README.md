## Kiln Controlling

- [jbruce12000/kiln-controller](https://github.com/jbruce12000/kiln-controller) - Turns a Raspberry Pi into an inexpensive, web-enabled kiln controller.
- [pllagunos/esp32-kiln-controller](https://github.com/pllagunos/esp32-kiln-controller) - ESP32 based Kiln controller with TFT display and webserver.
