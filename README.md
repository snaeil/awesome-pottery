# Awesome Pottery [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

This project wants to list awesome projects related to pottery.

## Contents

- [Kiln Controlling](#kiln-controlling)
- [Glaze Calculation](#glaze-calculation)

## Kiln Controlling

- [jbruce12000/kiln-controller](https://github.com/jbruce12000/kiln-controller) - Turns a Raspberry Pi into an inexpensive, web-enabled kiln controller.
- [pllagunos/esp32-kiln-controller](https://github.com/pllagunos/esp32-kiln-controller) - ESP32 based Kiln controller with TFT display and webserver.

## Glaze Calculation

- [theluckystrike/frit](https://github.com/theluckystrike/frit) - Free Mac app that reworks a glaze recipe when a material changes, moves one oxide to a target and finds fired test tiles by code.
